# 跟单进度跟踪系统 · UI 设计规范（清爽浅色简约）

> 版本：v1.0　|　日期：2026-08-19　|　设计：UI Designer
> 适用范围：tracker_web 跟单进度跟踪系统全新改版（可交互原型 + 本规范同步交付）

---

## 1. 设计目标与原则

本系统是一线**跟单员**日常高频使用的 B 端数据工具，核心场景是「盯交期、看进度、查异常、录工序」。设计以 **清爽、克制、低疲劳** 为基调：

1. **信息优先**：数据本身是主角，界面退后为容器；减少装饰、强调对比与对齐。
2. **一眼定位**：用分组侧边导航替代原有 15 个平铺顶部 tab，缩短查找路径。
3. **状态即视觉**：工序进度用「颜色块矩阵」做密度可视化，逾期/风险用语义色直接预警。
4. **一致性**：所有模块共用同一套令牌与组件，降低认知与开发成本。
5. **可访问性**：正文对比度 ≥ 4.5:1（WCAG AA），可键盘操作，焦点清晰。

## 2. 设计基础（Design Tokens）

### 2.1 色彩

**中性色（背景 / 文字 / 边框）**

| Token | 值 | 用途 |
|------|-----|------|
| `--bg` | `#F6F8FB` | 应用主背景 |
| `--surface` | `#FFFFFF` | 卡片 / 面板 / 弹窗 |
| `--surface-2` | `#F1F4F9` | 表头 / 次级填充 / hover 底 |
| `--border` | `#E8ECF2` | 描边 / 分隔线 |
| `--text-1` | `#1E2533` | 主文字 |
| `--text-2` | `#6B7488` | 次要文字 / 标签 |
| `--text-3` | `#9AA3B2` | 占位符 / 辅助说明 |

**品牌主色（清爽蓝）**

| Token | 值 | 用途 |
|------|-----|------|
| `--primary` | `#3B6FF5` | 主操作 / 选中 / 链接 |
| `--primary-50` | `#EEF3FF` | 主色浅底（选中项背景） |
| `--primary-100` | `#DCE7FF` | 浅底 hover |
| `--primary-600` | `#2F5BE0` | 主色按下 |
| `--primary-700` | `#2547B8` | 主色文字 |

**语义色（状态 / 预警）**

| Token | 值 | 用途 |
|------|-----|------|
| `--success` | `#16A34A` | 已完成 / 满足 |
| `--success-soft` | `#E7F6EC` | 成功浅底 pill |
| `--warning` | `#F59E0B` | 预警 / 临界 |
| `--warning-soft` | `#FEF3E2` | 预警浅底 |
| `--danger` | `#EF4444` | 逾期 / 风险 / 删除 |
| `--danger-soft` | `#FDECEC` | 危险浅底 |
| `--info` | `#3B6FF5` | 进行中（与主色同系） |

### 2.2 工序状态色（核心可视化）

| 状态 | 色块 | 说明 |
|------|------|------|
| 未开始 | `#C2C9D6` | 灰色，待推进 |
| 进行中 | `#3B6FF5` | 蓝色，当前卡点 |
| 已完成 | `#16A34A` | 绿色，已交付 |
| 预警 | `#F59E0B` | 琥珀，临近基准日 |
| 逾期 | `#EF4444` | 红色，已超期 |

> 注：此处红色表示「逾期/风险」属通用告警语义，与股票红涨绿跌无关。

### 2.3 字体

```
--font-sans: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "Microsoft YaHei", "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
--font-mono: "JetBrains Mono", "SFMono-Regular", Menlo, Consolas, monospace;

**字号阶梯（基础 14px）**

| Token | 值 | 用途 |
|------|-----|------|
| `--fs-xs` | 12px | 辅助说明 / 表内次要 |
| `--fs-sm` | 13px | 标签 / 按钮小字 |
| `--fs-base` | 14px | 正文 / 表格 |
| `--fs-md` | 16px | 区块标题 |

### 2.4 间距（8pt 基准）

`--sp-1` 4px · `--sp-2` 8px · `--sp-3` 12px · `--sp-4` 16px · `--sp-5` 20px · `--sp-6` 24px · `--sp-8` 32px · `--sp-10` 40px · `--sp-12` 48px

### 2.5 圆角 / 阴影 / 过渡

```

## 3. 布局与信息架构

### 3.1 总体布局

```
┌────────────┬─────────────────────────────────────────┐
│            │  顶栏：页面标题 · 全局搜索 · 操作 · 用户   │
│  侧边导航   ├─────────────────────────────────────────┤
│  (分组)     │                                          │
│            │            内容区（卡片/表格/图表）        │
│            │                                          │
└────────────┴─────────────────────────────────────────┘
   固定 240px          自适应，最大宽度 1320px 居中
```

### 3.2 导航分组（原 15 平铺 tab → 6 组）

| 分组 | 模块 |
|------|------|
| 概览 | 驾驶舱 |
| 生产进度 | 工序进度 · 甘特图 · 逾期呆滞 |
| 订单与合同 | 原始数据 · 订单明细 · 合同汇总 · 合同冗余 |
| 资料库 | 产品资料 · 发货需求 · 销售预测 |
| 分析 | 发货需求判断 |
| 系统 | 参数·字典 · 数据备份 |

- 侧边栏分组标题用小字号灰色；选中项用 `--primary-50` 浅底 + 左侧 3px 主色竖条。
- 当前模块名同步显示在顶栏左侧，右侧放全局搜索与用户 chip。

### 3.3 响应式断点

| 断点 | 宽度 | 行为 |
|------|------|------|
| 桌面 | ≥1280px | 侧栏常驻 240px，内容多列 |
| 笔记本 | 1024–1279px | 侧栏 220px，表格横向滚动 |
| 平板 | 768–1023px | 侧栏可收起（汉堡），KPI 2 列 |
| 手机 | <768px | 侧栏抽屉式，KPI 1 列，表格卡片化 |

## 4. 组件库

### 4.1 按钮 Button

| 变体 | 样式 | 用途 |
|------|------|------|
| 主要 `.btn-primary` | 主色填充白字 | 关键操作（新增、保存、批量更新） |
| 次要 `.btn` | 白底 + 边框 | 常规操作（搜索、导入、筛选） |
| 文字 `.btn-ghost` | 无边框透明 | 低强调（取消、重置） |
| 危险 `.btn-danger` | 红字 / 红浅底 | 删除 |

尺寸：默认 h=36px，小号 `.btn-sm` h=30px。圆角 `--r`。hover 轻微上浮 + 阴影；disabled 降透明度。聚焦可见 outline。

### 4.2 输入框 / 选择器

- 高度 36px，圆角 `--r`，边框 `--border`，聚焦时边框主色 + 浅光晕。
- 占位符用 `--text-3`。
- 下拉 `.select` 同高，右侧箭头。

### 4.3 数据表格 Table

- 表头：`--surface-2` 浅底、 `--text-2`、13px、字重 500、吸顶（sticky）。
- 行高 44px，hover 行 `--surface-2`；分隔用 1px `--border`（不用斑马纹，保持清爽）。
- 数字列右对齐、等宽字体；状态用 pill 标签。
- 支持行首复选框（批量）、行内「明细」链接。
- 横向滚动容器，移动端可卡片化。

### 4.4 标签 / 状态 pill

- 圆角 `--r-pill`，内边距 2px×10px，12px。
- 语义色浅底 + 同色深字（success/warning/danger/info/neutral）。

### 4.5 卡片 Card / KPI

- 白底、`--r`、1px 边框、`--sh-sm`。
- KPI 卡：大数字（`--fs-2xl`，字重 600）+ 标签（--text-2）+ 小趋势（↑/↓ 带色）。
- 图表卡：标题 + 画布区，内边距 `--sp-6`。

### 4.6 弹窗 Modal

- 遮罩 `rgba(16,24,40,.45)` 模糊；弹窗白底 `--r-lg` `--sh-md`，最大宽 520（宽版 760）。
- 结构：标题栏（标题 + 关闭 ×）/ 主体 / 底部操作（主操作右对齐）。
- 多种：通用编辑、工序批量更新、导入明细、批量粘贴。

### 4.7 反馈 Toast

- 右上角浮层，圆角 `--r`、左侧色条（success/info/danger），3s 自动消失，可堆叠。

### 4.8 分页 / 筛选条

- 筛选条：位于模块标题下，左标签右控件，换行自适应；「列名筛选」独立一行（工序进度）。
- 分页：左显示「共 N 条」，右页码按钮 + 每页大小。

## 5. 关键界面要点

### 5.1 驾驶舱（首页）

- 顶部 4–6 张 KPI 卡：在手待交付件数 / 金额、逾期合同数、本周应出货、工序完成率。
- 下方图表卡：完成率（环形）、各厂商在手金额 Top10（横向条）、运营组逾期分布（柱状）。
- 异常用语义色点出（如逾期金额标红）。

### 5.2 工序进度（核心模块）

- 顶部：搜索框 + 列名筛选行（合同号/产品编号/SPU/工艺品类/检验重点）+ 导入/模板/批量更新。
- 主表：**颜色块状态矩阵**——每一行一个「产品编号+合同号」聚合，工序列用色块表示状态；列含 SPU、订单数量、合同日期、出货日期、工艺品类、当前工序、完成度（进度条）、客诉点、检验重点（pill）、验货时间、验货结果、明细按钮。
- 交互：点击色块 → 录入该工序实际完成日；勾选多行 + 批量更新 → 统一设置某工序；明细按钮 → 弹窗看导入的明细行。
- 数据与原始数据表**解耦**（独立导入），改原始不影响此处。

### 5.3 数据型模块（原始数据 / 逾期 / 合同 / 资料库）

- 统一「筛选条 + 表格 + 分页」模板；资料库模块加「模板/导入/新增」三件套。
- 逾期/合同冗余额外带 KPI 摘要 + 图表，强调异常金额与分档。

## 6. 可访问性（WCAG AA）

- 文字对比：正文 `#1E2533` on `#FFFFFF` ≈ 13:1；次要 `#6B7488` ≈ 4.6:1（达标）。
- 焦点：所有可操作元素 `:focus-visible` 显示 2px 主色 outline + 偏移。
- 触控：按钮/可点色块最小 36×36，移动端 ≥44。
- 动效：遵循 `prefers-reduced-motion`，过渡可关闭。
- 语义：侧栏用 `<nav>`，表格用 `<table>`，弹窗 `role="dialog"` + `aria-modal`。

## 7. 交付物

- `prototype.html`：可在浏览器打开的可交互原型（侧边导航 + 驾驶舱 + 工序进度全功能 + 其余模块概览），自包含无外部依赖。
- 本规范：设计令牌、组件、布局、无障碍标准，供开发按图实现。

> 实施建议：先落地设计令牌与侧边导航骨架，再逐模块迁移；工序进度颜色块矩阵与批量/明细弹窗为体验重点，优先打磨。
