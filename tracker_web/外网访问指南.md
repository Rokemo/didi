# 外网访问指南（让同事/手机也能打开跟单网页）

> 当前网页跑在本机 `http://127.0.0.1:8731`，只有你这台电脑能开。  
> 要让**外网**（别的电脑、手机、外地同事）也能打开，需要把本机服务"穿透"出去。  
> 下面三种方法都不用买云服务器，数据**仍留在你电脑上**，只是访问通道经第三方转发。

4. 数据会经过隧道服务商（Cloudflare / ngrok）的服务器中转，属正常加密中转（HTTPS）。

## 方法一（推荐，免注册）：Cloudflare 快速隧道

**优点**：不用注册账号、自带 HTTPS、一行命令、最适合"现在就让外面打开看看"。

1. 下载 `cloudflared`（Windows 64位）：  
   <https://github.com/cloudflare/cloudflared/releases>  → 找 `cloudflared-windows-amd64.exe`，重命名为 `cloudflared.exe`。
2. 把 `cloudflared.exe` 放到任意文件夹（例如 `D:\tools\`）。
3. 打开**命令提示符(cmd)**，进到该文件夹：
   ```
   	cd /d D:\tools
   	cloudflared tunnel --url http://localhost:8731
   ```
4. 等待几秒，出现一行 `https://xxxx.trycloudflare.com` —— **这就是外网链接**，发给同事或手机浏览器打开即可。
5. 关闭这个命令行窗口 = 立刻停止外网访问。

（懒得敲命令可双击本目录的 `expose_cloudflare.bat`，前提是已把 `cloudflared.exe` 放到 `C:\Windows` 或已加入 PATH。）

## 方法二：ngrok（需免费注册）

**优点**：稳定些；**缺点**：现在必须注册拿 token。

1. 注册 <https://ngrok.com> （免费），后台拿到 `Authtoken`。
2. 下载 ngrok.exe，命令行：
   ```
   ngrok config add-authtoken <你的token>
   ngrok http 8731
   ```
3. 出现 `https://xxxx.ngrok-free.app` 即为外网链接。  
   （本目录 `expose_ngrok.bat` 已写好 `ngrok http 8731`，配好 token 后双击即可。）

## 方法三（长期固定入口，不依赖第三方）：路由器端口转发 + 动态域名

适合"长期给团队用、想有固定网址"，但要在你家/公司路由器上操作，略技术：

1. 让网页监听所有网卡：启动时设 `HOST=0.0.0.0`（例如 `set HOST=0.0.0.0 && run.bat`），  
   或改 `server.py` 第 32 行 `HOST = "0.0.0.0"`。
2. 登录路由器 → 端口转发/虚拟服务器 → 把 **外部端口 8731 → 你电脑内网 IP:8731**（TCP）。
3. 你电脑建议设**固定内网 IP**（网卡 IPv4 手动指定），否则路由转发会失效。
4. 没有固定公网 IP 的话，去申请一个**动态域名（DDNS）**（如花生壳、No-IP），把域名绑到你的动态 IP。
5. 外网访问：`http://你的域名:8731`（建议再套一层 HTTPS，否则密码明文传输）。

## 重要提醒

- **隧道/服务必须和运行 `server.py` 的同一台电脑上、且保持运行**。本机演示服务关了，外网链接立刻失效。
- 当前服务跑在 WorkBuddy 沙箱里，**沙箱会话结束时服务会停**；若要长期外网可访问，请把 `tracker_web` 整个文件夹复制到一台**常开电脑**上，用 `run.bat` 启动后再开隧道。
- 不用的時候关掉隧道命令行，链接即失效，最省心。
