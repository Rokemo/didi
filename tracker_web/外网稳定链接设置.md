# 跟单系统 · 脱离沙箱运行 + 稳定外网链接设置

适用于：把 `tracker_web/` 整个目录复制到你自己电脑后，独立运行并对外网开放。

---

## 一、本机独立启动（脱离 WorkBuddy 沙箱）

直接**双击 `启动.bat`** 即可（无需 WorkBuddy）。它会：

1. 释放 8731 端口残留进程；
2. 自动选 Python：优先用受管 venv（已带 openpyxl），否则用系统 `python`（缺 openpyxl 会自动 `pip install`）；
3. 启动 `server.py`，并自动打开浏览器 `http://127.0.0.1:8731`。

> 关闭那个黑窗口 = 停止服务 = 网页打不开。
> 想后台常驻：用 `外网_稳定_Cloudflare.bat`（见下）或把 `启动.bat` 放到「任务计划程序」开机自启。

---

## 二、稳定外网链接（推荐：Cloudflare 命名隧道）

**为什么稳？** 命名隧道的地址是 `https://<隧道ID>.cfargotunnel.com`，隧道 ID 创建后**永久固定**，重启电脑/重跑脚本都不变。完全免费，只需一个 Cloudflare 账号。

### 一次性准备（约 2 分钟）
1. 下载 `cloudflared.exe`：https://github.com/cloudflare/cloudflared/releases
   （放到 `C:\Windows` 或把目录加入系统 PATH，重开命令行生效）
2. 浏览器登录 Cloudflare 免费账号后，命令行执行一次：
   ```
   cloudflared login
   cloudflared tunnel create didi
   ```
   前者会弹浏览器授权；后者在本机生成命名隧道凭证。

### 日常使用
双击 **`外网_稳定_Cloudflare.bat`** → 自动起本地服务 + 起命名隧道 → 输出固定外网地址。
关闭窗口即停止外网访问（本地服务仍在）。

> 想用自己的域名（如 `didi.你的域名.com`）：再执行一次
> `cloudflared tunnel route dns didi didi.你的域名.com`（需该域名托管在 Cloudflare）。

## 三、备选方案对比

| 方案 | 稳定性 | 费用 | 前置 |
|------|--------|------|------|
| **Cloudflare 命名隧道** | ✅ 固定地址 | 免费 | 免费账号 + `cloudflared login` 一次 |
| Cloudflare 快速隧道（`expose_cloudflare.bat`） | ❌ 每次变 | 免费 | 仅装 cloudflared |
| ngrok（`expose_ngrok.bat`） | ❌ 免费版每次变；预留域名需付费 | 免费/付费 | ngrok 账号 + token |
| WorkBuddy 一键外网 | ⚠️ 会生成独立副本（独立库/密码），曾出现「账号密码错误」 | 随订阅 | WorkBuddy 内触发 |

**结论**：要「稳定」就走 **Cloudflare 命名隧道**（方案二）。快速隧道/ngrok 仅适合临时演示。

## 四、常见问题

- **`server.py` 启动报 ImportError: openpyxl** → 运行 `python -m pip install openpyxl`（启动器已自动处理）。
- **外网打开空白/连不上** → 先确认本机 `http://127.0.0.1:8731` 能开；再确认隧道窗口无报错；企业网络可能拦截，换手机热点测试。
- **想要开机自启** → Windows「任务计划程序」建基本任务，操作指向 `启动.bat`，触发器「登录时」。
- **数据在哪** → 本地 `tracker.db`，建议定期用页面「数据备份」或复制该文件到云盘。
