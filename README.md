# didi · 跨境电商跟单进度跟踪

跨境电商采购跟单的进度可视化、多部门协同与指标分析系统。包含**网页版跟单系统**（主交付物）与一套 **Excel 版（v5）构建管线**。

## 快速开始（网页版）

1. **准备环境**：安装 Python 3.10+（安装时勾选 *Add to PATH*），并确保已装 `openpyxl`（`pip install openpyxl`）。
2. **启动**：双击 `tracker_web/启动.bat`。脚本会自动释放 8731 端口、定位 Python、启动服务并打开浏览器。
3. **访问**：浏览器打开 `http://127.0.0.1:8731`。

> 默认是**免登录**模式（打开即管理员，可直接增删改全部数据）。若要分账号分权限（管理员 / 跟单员 / 只读），在启动前设置 `AUTH_ENABLED=1` 并创建账号，页面会自动出现登录框。

## 让团队 / 外部访问

- 同一办公室：让服务监听局域网（`HOST=0.0.0.0`）+ 防火墙放行 8731，同事用内网 IP 访问。详见 `tracker_web/外网稳定链接设置.md`。
- 异地 / 外地工厂：云服务器 + Nginx 反代 + HTTPS 最稳。
- 临时演示：`cloudflared tunnel --url http://localhost:8731` 可得临时外网网址（每次重启会变）。

## 技术栈

- 网页版：Python 标准库 `http.server` + `sqlite3`（零外部依赖，仅 `openpyxl` 用于 Excel 导入）+ 原生前端 + Chart.js。
- 端口：`8731`（可用环境变量 `PORT` 改；`HOST` 改绑定地址）。
